\# FurniRent – Furniture Rental Website



FurniRent is a full-stack furniture rental web application that allows users to browse furniture, create accounts, rent furniture, and manage their rentals. An admin dashboard provides tools to manage furniture and rental orders.



\## Features



\* User registration and login

\* User authentication and authorization

\* Browse available furniture

\* View furniture details

\* Rent furniture

\* View personal rental history

\* Admin dashboard

\* Add, update, and delete furniture

\* Manage rental orders

\* Furniture availability management

\* MongoDB database integration

\* REST API backend

\## How to Run the Project



\### 1. Clone the repository



```bash

git clone https://github.com/ayesha-siddiqa-codes/FurniRent.git

cd FurniRent

```



\### 2. Install backend dependencies



```bash

cd backend

npm install

```



Create a `.env` file inside the `backend` folder and add your environment variables.



\### 3. Start the backend



```bash

npm start

```



\### 4. Install frontend dependencies



Open another terminal:



```bash

cd frontend

npm install

```



\### 5. Start the frontend



```bash

npm run dev

```



Then open the local URL shown by Vite in your browser.
